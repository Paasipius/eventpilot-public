What is EventPilot?

EventPilot is a Discord bot that helps communities organize events, manage member signups, send reminders, track check-ins, and view attendance reports.

Features

  • Create and manage server events
  • Join, Maybe, and Leave buttons
  • Automatic event reminders
  • Member check-ins
  • Attendance and no-show reports
  • Persistent event information

Free Beta

EventPilot is currently free to use during beta. Standard beta access supports up to three active events per server.

There are no required payments or public subscriptions. Voluntary donations may be introduced later to support hosting and future development.
