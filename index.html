What Is EventPilot?

EventPilot is a Discord bot that helps communities organize events, manage member signups, send reminders, track check-ins, and view attendance reports.

Features

  • Create and manage server events
  • Join, Maybe, and Leave buttons
  • Automatic event reminders
  • Event check-in tracking
  • Attendance and no-show reports
  • Saved event and server information
  • Default event channel configuration

Currently in Free Beta

EventPilot is currently free to use during beta. Standard beta access allows up to three active events per server.

There are no required payments or public subscriptions at this time.

A voluntary support or donation option may be introduced later to help with hosting, maintenance, and future development.
