EventPilot Privacy Policy

Last updated: October 30, 2026

1. Introduction

EventPilot is a Discord bot that helps communities create events, manage signups, send reminders, track check-ins, and generate attendance reports.

This Privacy Policy explains what information EventPilot collects, how it is used, and how users can request deletion.

2. Information We Collect

EventPilot may store the following:

  • Discord server IDs
  • Discord channel and message IDs
  • Discord user IDs
  • Usernames or display names associated with events
  • Event names, descriptions, dates, and times
  • Event time zones and capacity settings
  • Event signup choices such as Join and Maybe
  • Event check-in information and timestamps
  • Event creator information
  • Server settings and beta access levels

EventPilot does not intentionally collect private message contents, passwords, or payment card details.

3. How Information Is Used

Stored information is used to:

  • Create and manage Discord events
  • Track event signups and attendance
  • Send scheduled reminders
  • Generate attendance and no-show reports
  • Save server configuration
  • Enforce beta event limits
  • Maintain and troubleshoot EventPilot

Event details and attendance information may be displayed within the Discord server where an event is managed.

4. Data Storage

EventPilot uses PostgreSQL database storage hosted through Railway. Development or administrative copies of data may also be stored when necessary for operating or maintaining the service.

Access to stored information is restricted to the application operator and systems or providers needed to operate EventPilot.

5. Data Retention

EventPilot retains event and configuration data to provide its services. There is currently no automatic deletion schedule for all stored records.

Removing EventPilot from a server does not necessarily delete its previously stored records automatically. Data deletion may be requested through support.

6. Data Sharing

EventPilot does not sell user information.

Information may be processed by hosting and database service providers, disclosed when legally required, or used to investigate security incidents and misuse.

7. Donations and Payments

EventPilot is currently free to use during beta. There are no required payments or public subscriptions at this time.

A voluntary donation option may be added later to help support hosting, maintenance, and development.

EventPilot does not currently collect or store payment card details.

8. Security

Reasonable precautions are taken to protect stored information, including restricted access to application credentials and database services.

No online service can guarantee absolute security.

9. Data Deletion and Privacy Requests

Users and server administrators can contact EventPilot support to request deletion of information associated with their Discord account or server.

Requests may require verification and will be reviewed subject to applicable legal and operational requirements.

For privacy matters, request a private support conversation rather than posting personal information in a public channel.
